# ReShattered Pixel Dungeon

[ReShattered Pixel Dungeon](https://github.com/jjc-cloud/re-shattered-pixel-dungeon) is an open-source traditional roguelike dungeon crawler with randomized levels and enemies, and hundreds of items to collect and use. It's based on the [source code of Shattered Pixel Dungeon 4.0](https://github.com/00-Evan/shattered-pixel-dungeon), by [00-Evan](https://shatteredpixel.com/).

## Shattered Pixel Dungeon is still undergoing updates. Why create this dungeon?
With the update of Shattered Pixel Dungeon, the gameplay has become rather lackluster. Perhaps it's just for me alone, anyway I create this dungeon.

## Main changes to SPD:
- All heroes have unique initial attributes.
- More abundant environmental interaction, such as ambient light in the environment, flexible terrain modification.
- More interactive regional terrain.
- More talents, items, gameplay mechanics.

Still under construction，issue reports of all kinds (bug reports, feature requests, suggestions, etc.) are welcome.
