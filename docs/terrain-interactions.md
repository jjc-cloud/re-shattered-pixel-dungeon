# 地图元素的类别交互

地图元素仍由地形格表示，不是 Actor。作用来源声明类别，楼层规则决定该格对这一类别的响应，作用来源继续负责伤害、状态、动画和回合结算。规则不包含物品、怪物、木桶或铁笼的类名判断。

## 配置关系

入口为 `level.interactions()`，仅在显式配置时创建组件。运行中的查询使用可空的 `level.terrainInteractions`，不会因为一次普通攻击自动创建地图数据。

```java
import com.shatteredpixel.shatteredpixeldungeon.levels.TerrainInteractions;
import com.shatteredpixel.shatteredpixeldungeon.levels.TerrainInteractions.Source;
import com.shatteredpixel.shatteredpixeldungeon.levels.TerrainInteractions.Response;
import com.shatteredpixel.shatteredpixeldungeon.levels.TerrainInteractions.Rule;

// 可以将同一规则赋给墙、雕像、区域装饰等任意地形格。
// Rule 不可变，on() 返回新规则；定义一次后在多格之间共享。
Rule material = Rule.NONE
    .on(Source.EXPLOSION, Response.replaceWith(Terrain.EMPTY_DECO))
    .on(Source.DISINTEGRATION, Response.replaceWith(Terrain.EMPTY_DECO))
    .on(Source.ELECTRIC, Response.CONDUCT);

level.interactions().setDefault(Terrain.REGION_DECO, material);
level.interactions().setOverride(cell, Rule.NONE); // 这一格不响应已接入的类别
level.interactions().clearOverride(cell);         // 恢复类型默认值

// 为已有地形追加点击能力，同时保留其余类别的原有行为。
Rule clickable = Rule.LEGACY.on(Source.CLICK, Response.DESTROY);
level.interactions().setOverride(otherCell, clickable);
```

优先级为逐格覆盖、当前楼层的地形类型默认值、原有行为。`Rule.LEGACY` 是显式使用旧行为，`Rule.NONE` 是明确拒绝，二者不能混用。区域通过各自的 Level 实例配置默认表；不会改变全局 `Terrain.flags` 或把普通墙统一变成可破坏地形。

| 类别 | 含义 |
| --- | --- |
| `CLICK` | 英雄对地形的直接操作 |
| `EXPLOSION` | 产生地形破坏的爆炸 |
| `DISINTEGRATION` | 解离／破坏性射线 |
| `ELECTRIC` | 电作用，包括单点、连锁、范围脉冲和持续电场 |
| `FIRE` | 燃烧对地形的作用 |

| 响应 | 含义 |
| --- | --- |
| `LEGACY` | 由调用方继续原有行为 |
| `IGNORE` | 拒绝该类别，不能再回落到原有破坏逻辑 |
| `replaceWith(terrain)` | 换成指定地形，更新通行、视线和地图显示 |
| `DESTROY` | 复用该区域的 `Level.destroy()`，例如不同区域装饰具有不同破坏结果 |
| `CONDUCT` | 可作为这一类别的传播节点，由传播事件展开相连节点 |

响应表可以为电配置地形替换，而不只是导电；传播器也按类别查询，而不绑定具体攻击者。是否产生传播仍取决于作用路径：单格 `affectTerrain()` 不擅自把一个效果变成范围攻击。

## 作用路径接入

- **单格地形作用：** `level.affectTerrain(cell, Source.XXX)`。返回地形是否改变；范围作用累计结果，在结束时统一 `Dungeon.observe()`。适合既有路径逐格报告爆炸、射线和燃烧。
- **单点作用及其传导：** `TerrainPropagation.point(level, category, cell, primary, excluded, effect)`。框架扩展目标并去重，调用方的 `TargetEffect` 负责原效果；不凭伤害来源类名猜测属性。
- **范围作用：** `TerrainPropagation.event(level, category)`；无相关响应时返回 `null`。向事件报告 `touch(cell)` 后调用 `extendTargets()`，或用 `extendCells()` 扩展已有作用格集合。两者会结束并归还事件。只报告真正发生作用的格，不报告预警、瞄准线或纯视觉效果。
- **原有连锁与持续作用：** 可使用 `begin`、`seed`、`next` 逐步访问连通节点，将新增目标接回原有计算。手动遍历必须调用 `end()`；不要在归还后继续使用借用的事件。

`touch` 接触本格及八向相邻传播节点；节点之间八向连接。`seed` 只接触指定节点。所有传播结果在原来源的伤害／状态结算前收集，原有友军过滤、免疫、伤害归属和持续时间由来源保留。传播节点不计入雷霆法杖的受击人数；导体不会自动获得水面的全额伤害加成。

现有路径的关联接入：

| 公共作用路径 | 随之参与的来源 |
| --- | --- |
| 破坏性 `Bomb.explode` | 普通炸弹、调用此分支的炼金炸弹、召唤炸弹及复用它的技能 |
| 射线逐格作用 | 解离法杖、邪眼死亡凝视、秘库激光 |
| 燃烧地形作用 | `Fire`、`Inferno`、天狗火焰地形作用、焰浪魔杖近战的燃烧清理 |
| 连锁电作用 | 雷霆法杖；共享 `Shocking.arc` 的电击附魔、电元素及其子类 |
| 持续电场 | `Electricity`，包括电陷阱、雷暴药剂及复用它的职业能力 |
| 单点电作用 | 电击飞镖、DM-100 电击、秘库元素 Boss 电反击、秘库哨卫的实际射击 |
| 电范围／延迟脉冲 | 闪光弹的电击部分、电击符石、诅咒法杖电击、电塔、天狗电击装置、DM-300 场地电能、秘库元素 Boss 雷击 |

纯充能的电势刻印、造水的风暴云、震爆炸弹的心智攻击不因为名称或特效而产生电传播。矿洞挖掘保留其原有十字镐、饥饿、金矿与水晶任务逻辑；它没有被伪装成普通点击或爆炸。以后新增来源若复用上述作用路径，会获得同类地形响应；独立的新作用路径只需报告类别，不需逐个认识元素。

爆炸使用破坏前距离图补充接触到的实体表面，不把可炸墙加入传播通道。同次爆炸不会穿过刚被炸开的墙；后续爆炸根据当时的新地形计算。解离射线先计入原地形的穿墙加成，再处理替换。

## 生命周期与性能

- 未启用的楼层没有规则组件、逐格规则数组、传播事件、额外 Actor 或周期扫描。已有 Actor 的更新频率不变；电场只在其原本更新时处理相关规则。
- 类型表固定为 256 项；逐格覆盖数组在第一次覆盖时分配。热路径采用索引查表，规则注册和保存不在帧循环中进行。
- 传播使用队列和访问代次，不递归、不修改 `PathFinder.distance`，不为每个节点重建全图距离图。访问标记按需分配；连续事件复用楼层内缓存，嵌套事件借用不同实例。
- 缓存初始化需要与地图大小对应的内存；初始化后的遍历工作随本次连通节点数增长。目标位置索引每个传播事件最多建立一次。电场继续使用原有区域遍历，不为每个导体追加一次全图扫描。
- `Level.set()` 更换地形时清除该格的覆盖配置；生成器应先绘制地形再配置规则。直接写 `map[]` 绕过这些维护，运行中的地形改动应使用 `Level.set()`。
- 响应定义、类型默认值和逐格覆盖随楼层保存；缓存不保存。没有新字段的存档按未启用处理，不迁移旧地形，也不为改名的炸弹保留别名。
- 运行时改地形会重建盖住该格的自定义图层（`GameScene.updateCustomTiles()`，由 `updateMap()` 统一调用）：自定义图层只在场景建立时创建一次，不重建就会留着按旧地形画出的贴图。重建按帧合并，只有脏格落在图层矩形内（含一格余量，兼顾读下一行地形的延伸图层）才整组重建，以保持同组图层的先后顺序；`Group.add()` 对已属于该组的可视对象是空操作，复用可视对象的图层不会重复挂载。

## 验证与演示

执行 `:core:terrainInteractionRegression`。测试覆盖任意地形的组合规则、拒绝与继承、序列化、真实炸弹的墙面接触与后续爆炸、英雄动作动画回调、随机传播拓扑、同源目标去重、异类响应、嵌套事件隔离、缓存复用和电场自然到期。动作测试在无图形环境中验证到 `ready()` 刷新攻击指示器之前；实际画面仍需桌面游戏检查。

测试还在 32×32、128×128、256×256 地图中保持同一块 64 格传播网络，输出实际实现的预热耗时并断言每次仅访问 64 个节点。耗时不包含完整图形渲染，不能据此推断移动端帧率。

普通地图生成时已配置区域地形规则：下水道木桶和恶魔大厅岩石瓦砾可由装备武器的英雄点击摧毁；监狱牢笼与矿洞金属架构导电；各区域雕像（恶魔大厅显示为台柱）被破坏性爆炸摧毁后变为余烬，解离射线不摧毁雕像。下水道木桶逐个以十分之一概率生成带标记的贴图变体，摧毁后以 75% 概率调用 `Gold.random()`，其余调用 `Generator.random()`；物品生成后使用现有的落地动画。草地墓室的原始规则是整组坟墓只选一座生成随机物品，其余为金币；木桶按用户选择保留独立概率。木桶与瓦砾的摧毁粒子沿用石化雕像的彩色 `Splash`，分别使用木色和石色；标记木桶跳过会遮住新贴图的旧地形前景图块。

破坏性爆炸和解离射线把实际破坏的地毯记录为 `Carpet.DESTROYED`，与原本就留空的 `Carpet.SKIP` 区分。普通地面露出普通余烬，原来是特殊地面的格露出特殊余烬；都市雕像经解离后仍保持阻挡与前景，只将底部换成对应余烬。入口、出口和没有余烬底图的台座保留原地毯图层：两条路径都必须先确认该格会露出余烬（或已经是余烬）才记录破坏，不能把「不能变成余烬」的格直接记成留空——否则地毯会连同贴图一起消失，却在地面上什么都不留，和解离射线出现分歧。`EMPTY_DECO` 是不可燃的装饰地面，但 `Level.destroy()` 一直把它和 `EMPTY` 同等看待，因此地毯盖住的 `EMPTY_DECO` 与 `CUSTOM_DECO_EMPTY` 一样露出普通余烬（都市雕像入口／出口房铺的入口地毯就落在 `EMPTY_DECO` 上）。鼠王房雕像不是普通地形，而是 `RatKingRoom` 的自定义装饰图层按 `CUSTOM_DECO` 画出来的，因此在下水道 Boss 层单独配置了爆炸规则：炸掉后直接换成可通行的普通余烬 `EMBERS`（房间自身铺的是特殊地面，是木板地面，余烬仍按普通地面走），雕像连同其前景与延伸图层一起消失。解离射线对鼠王房雕像无效——`affectTerrain` 里那行判定写在地毯循环内部，而雕像都在地毯矩形之外。特殊地面余烬是各区域地形图集第 1 行的索引 13、14（`EMBERS_SP`、`EMBERS_SP_ALT`），七个区域图集都已补上，因此所有区域都会生效。矮人王关（深度 20）通往王座的两条一格宽直毯原先是 `city_boss.png` 的地面图层画的，因此不参与这套破坏管线；现在改成真正的 `Carpet` 图层，覆盖王座向下的 1×4 与入口走廊的 1×6（中间的门把两段隔开）。王座那圈 3×3 平台仍由地面图层原样绘制，不做改动。地面图层整层铺满，必须排在地毯之前注册（`build()` 里那处 `customTiles.add` 因此提前了），否则会盖住地毯以及它被破坏后留下的过渡图。雕像底座余烬使用都市地形图集第 9 行的索引 132–135，只维护都市一套：雕像与地毯同格仅出现在都市（`StatuesRoom` 及其入口／出口变体和 `HallwayRoom` 会在地毯格上铺 `STATUE`，图书馆环、秘库、野心小鬼房与王鼠房都不铺雕像），其他区域本身没有这个需求。洞穴与下水道图集在索引 132–135 上是矿井水晶、巨石和标记木桶的贴图，不能当雕像余烬使用。地毯重绘先确定整块地毯的完整格与破损格，再对每个余烬格检查四向完整地毯及原地毯外缘，从索引表中选取一张过渡图；不把已补上过渡图的余烬当作完整地毯。矮人都市使用 `carpet.png` 第 7–9 行（索引 96–110、112–141）；第 9 行的 128–135 是连接单侧地毯时靠近外缘的修正图，136、137 分别是单格高横条和单格宽竖条的相对两侧连接图，138–141 是三向形状（只缺一边）里缺口那一侧正好落在地毯外缘时的图。通道型（只连对边）在自己贴着地毯外缘的单侧需要单独的图，由 `STRAIGHT_DAMAGE` 表选择：横毯贴上／下缘与竖毯贴左缘用块内的 111／142／143；竖毯贴右缘那一张画在装饰行（索引 90／92／94，三个区域各一张，形状相同、配色跟随各自区域块），因为各区域块都已排满 48 格、放不下第 49 张。它在表里用 `OUT_OF_BLOCK` 占位，取用时按 `damageBase` 换成绝对索引；这几个索引落在区域块之外，是唯一的例外。都市与监狱／矿洞两块的 49 个状态至此都有专属图。长边中段仅连接单侧时使用第 7 行的完整边图，不使用两端留白的 124–127；单向型那 16 处"共用同一张图"的差异都落在连接方向的反面，而共用图在该侧的覆盖只有 0～8/48，实际等价，不需要额外补图。索引 100 已补为“仅连接上方、左右都不是外缘”的图。破坏过渡图按区域分三块，形状都与都市块逐一相同（换色复制）：第 7–9 行（96–143）都市红，第 10–12 行（144–191）监狱与矿洞蓝灰，第 13–15 行（192–239）下水道绿。区域到基址的映射是：`regionOfs` 48 → 96（都市，王座厅与秘库支线同在 depth 16–19／48），0 → 192（下水道，实际只有王鼠房铺地毯），16／32 → 144（监狱与矿洞，目前没有地毯），其余区域不启用。⚠️ 绿块（192–239）还缺 `visual` 14，也就是索引 206（"竖毯内部"那张，对应 110），补上之前下水道那一个形状不画任何过渡图。破坏记录随楼层保存。

`TestStart.TERRAIN_INTERACTION_DEMO` 默认关闭。测试开局启用后，还会选取一处不紧贴出入口的普通墙，使用装饰墙外观并标记为接受爆炸／解离；演示规则只用于测试此额外墙面。

## 震爆炸弹名称

英文类名改为 `PsionicBomb`，贴图常量改为 `PSIONIC_BOMB`，配方和图鉴引用同步。中文仍显示“震爆炸弹”，效果和描述不变。中文文本位于 `items_zh.properties` 的 `items.bombs.psionicbomb.*` 三个键；不维护其他语言，也不添加旧类名的存档别名。
