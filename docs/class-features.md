# 职业特色

所有职业说明仅维护中文。

| 职业 | 效果 |
| --- | --- |
| 战士 | 每回合额外恢复最大生命值的 0.1%，与自然回血共用进度和结算。 |
| 法师 | 全部法杖使用魔杖的充能缩放系数 0.75，同样缺失充能数时恢复速度一致；神器自然充能速度 ×0.85。 |
| 盗贼 | 饥饿增长与饥饿伤害积累速度 ÷1.2；被动搜索概率获得早期版本的职业优势；法杖自然充能速度 ×0.85。 |
| 女猎手 | 隐匿值 +2，直接影响怪物察觉概率。 |
| 决斗家 | 初始双武器栏，装备刺剑与破旧的短剑，可免费交换主副武器并使用各自武技。 |
| 勇士 | 保留武技上限 +2、武技充能速度 +50%；普通攻击先主手再副手，副手伤害倍率 0.5，要求目标存活、副手范围可达且力量达标。一次普通攻击只花费主手攻击时间，武技、投掷与空手姿态不触发追击。 |
| 武僧 | 失去两个武器栏；副手占用释放为背包容量，主手栏变为右侧额外的神器／戒指栏。转职时先释放容量，再收入武器，放不下则掉在脚下；诅咒不会阻止转换，也不会被自动净化。神器、法杖自然充能速度 ×1.2。 |
| 牧师 | 神器自然充能速度 ×1.15；敌人造成的伤害在减伤与护盾吸收后，以 `剩余伤害 ×115÷100` 向下取整，再扣除生命。敌人本体和现有伤害来源识别所支持的敌人法术适用；饥饿与友军伤害不适用。 |

武僧的无羁之魂只计算护甲：一级天赋对三阶及以下护甲提供 +100% 内力获取；二级对二阶及以下提供 +150%；三级对一阶提供 +200%。更高阶护甲保留前级收益，不穿护甲无加成。点满只获得一件布甲。额外神器／戒指栏支持装备替换、卸装、被动效果、鉴定、祛邪、遗失背包与存档；仍不能重复装备同种神器。

## 早期盗贼依据

本地完整 Git 历史保留了作者早期提交：

- `f8244d013`（v0.6.2，重做盗贼与斗篷）之前，盗贼饥饿结算间隔是普通职业的 1.2 倍；这同时放缓饥饿增长和饥饿伤害。
- `a5df5e9b5`（v0.6.2，重做隐藏门与搜索）之前，发现概率为 `1 - base^((1 + min(等级, 9))/2)`，盗贼的 base 为 0.85，普通职业为 0.90。

当前实现保留现代搜索范围、主动搜索必定成功及不可搜索陷阱等规则，将上述两条旧概率之差作为盗贼的额外被动搜索概率。一级多 5 个百分点，九级及以后约多 14.68 个百分点。这避免直接替换为旧概率后降低现代陷阱发现率。

## 验证

`ClassFeaturesRegression` 在实现后执行，覆盖职业充能、耐饿、搜索、隐匿、牧师护盾后伤害、勇士追击条件、武僧武器移出与背包溢出、三枚戒指／三件神器、额外栏位存档、卸装与祛邪、内力获取与天赋赠品。各回归入口只复用无窗口资源初始化，不连带执行其他测试。

运行需要编译后的主程序类、libGDX/JSON 依赖以及 `gdx-platform` 的 `natives-desktop` JAR，主类为 `com.shatteredpixel.shatteredpixeldungeon.ClassFeaturesRegression`，从项目根目录运行；无需打开游戏窗口。

本次按当前实现更新了旧战士测试：狂战士纹章守护阈值为累计实际生命损失 70%，零怒气名称为“愤怒”。后续只运行本次修改涉及的验证。尚未进行游戏内目视验收。
