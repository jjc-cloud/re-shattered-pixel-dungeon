# 徽章显示与美术维护说明

适用于当前 `codex/achievement-expansion` 分支，核对日期：2026-10-04。

## 新增成就的展示规则

显示规则位于 `core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/Badges.java`，界面入口位于同目录下的 `ui/BadgesGrid.java`。

- 游戏内“本局”仅显示本局已取得的徽章；查看未解锁目标需要切换到“全部”。主菜单日志使用全局徽章视图。
- `tierBadgeReplacements` 折叠同一系列：已解锁部分只显示最高级，未解锁部分只显示下一等级。
- `prerequisiteBadges` 在前置徽章未获得时隐藏部分目标，主要用于 Boss 挑战和高阶目标。
- `summaryBadgeReplacements` 在汇总成就解锁后折叠其组成徽章。
- `BadgeType.HIDDEN` 是内部进度记录，不作为独立徽章显示。

新增成就的等级链：

| 系列 | 初始显示 | 后续显示 |
| --- | --- | --- |
| 随机获胜 | 随机获胜！ | 解锁后显示下一目标“混沌终局！”；取得混沌终局后，已解锁列表仅保留高阶 |
| 速通 | 速通玩家 | 取得后显示下一目标“借过一下”，再下一等级为“？？？” |

新增 12 项均为 `BadgeType.LOCAL`，都是非隐藏成就。在“全部”中，独立成就未解锁时也会显示；连锁成就只显示最高已解锁徽章及紧接着的一个未解锁目标。

在完全没有相关解锁记录的全局视图中，新增 12 项会显示其中 9 项：8 项独立目标与速通一级。混沌终局在取得“随机获胜！”后出现，速通二级在取得“速通玩家”后出现，速通三级在取得“借过一下”后出现。后续等级尚未轮到展示不等于 `BadgeType.HIDDEN`。

图标编号已经独立分配；等级链复用 `tierBadgeReplacements`、`leaveBest` 和 `leaveWorst`，无需新增显示方法。

## 图案、外框和底色在哪里

图集：`core/src/main/assets/interfaces/badges.png`。

当前实际尺寸为 **128×384 像素**，每枚徽章占 **16×16 像素**，每行 8 枚，共 24 行。图集编号从 0 开始，从左到右、从上到下；本说明中的行、列均从 1 开始数。

徽章中心图案、铜/银/金等外框、徽章内部背景均是这个 16×16 小图中的像素，没有分别绘制的图层，也没有 `frameStyle`、`backgroundStyle` 等字段。透明区域由 PNG 的 alpha 通道控制。

`Badges.Badge` 每项括号内的整数是图集编号，例如 `VICTORY_CHAOS(136)`。枚举项位于 `//diamond` 注释下不会自动生成钻石外框；实际样式只取决于编号指向的小图。

坐标换算（以左上角为原点）：

```text
x = (编号 % 8) × 16
y = (编号 / 8 的整数部分) × 16
裁剪区域 = 从 (x, y) 开始的 16×16 像素
```

## 独立更换某个成就的样式

1. 用像素绘图软件打开图集，开启 16×16 网格。
2. 按上表定位第 18–19 行的独立图块。画布已扩展为 **128×384**，无需再扩展；保持宽度 128、左上角原点及原图内容不动。
3. 复制喜欢的外框及底色到新图块，再绘制中心图案，保持 16×16 大小；使用像素笔刷，缩放预览时使用最近邻。
4. 代码已将新增徽章指向 **136–147**，在对应图块内绘图即可，无需再次修改编号。
5. 保存 PNG，重新构建运行。检查徽章列表、点击后的详情窗口及解锁弹出的徽章效果。

例如，在 `(0, 272)` 绘好 16×16 的混沌终局徽章后，代码会通过以下已配置编号直接读取：

```java
VICTORY_CHAOS               ( 136 ),
```

这 12 个位置均位于当前画布内。填入贴图并保存 PNG 后重新构建、重新启动游戏，即可看到新图；仍为空白的图块会显示为空白。

不要改变图集宽度或整体缩放旧图片。编号采用“行号 × 每行数量 + 列号”，改变宽度会改变每行数量，导致现有编号指向错误位置。

## 其他视觉效果

- 未解锁徽章在 `ui/BadgesGrid.java` 与 `windows/WndBadge.java` 中使用 `brightness(0.4f)` 压暗。替换图片后看起来暗，可能只是未解锁状态。
- `effects/BadgeBanner.java` 负责图集读取、解锁弹出动画和闪光。详情窗口中徽章显示为 2 倍，解锁动画默认显示为 3 倍，不需要因此把源小图画大。
- 闪光位置通常根据图块上方像素自动寻找；特殊形状可在已有 `highlightPositions` 表中指定图块内的闪光坐标。
- 如果“背景”指整块日志面板或详情窗口的背景，而非徽章内部底色，它属于界面窗口皮肤，修改徽章 PNG 不会改变它。
- 要把图案、外框、底色改为运行时分别配置，需要另做绘制层组合；当前改 PNG 和编号即可完成每枚徽章的独立外观，不需要新增方法。
